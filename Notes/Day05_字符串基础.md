# Day05 Python字符串基础


# 1. 字符串（str）

字符串是Python中的一种数据类型，用于存储文本。

例如：

```python
name = "Python"
```

可以通过：

```python
type()
```

查看类型：

```python
print(type(name))
```

输出：

```
<class 'str'>
```


---

# 2. 字符串的三种定义方式


## 2.1 双引号定义

```python
s1 = "Hello"
```

适合普通字符串。


---

## 2.2 单引号定义

```python
s2 = 'Python'
```

单引号和双引号功能相同。


例如：

```python
name = "Tom"
```

也可以：

```python
name = 'Tom'
```


注意：

单引号和双引号定义的字符串不能跨越多行。


错误：

```python
s = "Hello
Python"
```


---

## 2.3 三引号定义多行字符串

Python支持：

```python
"""
内容
"""
```

或者：

```python
'''
内容
'''
```

定义多行字符串。


示例：

```python
s3 = """
尊敬的客户：
感谢您选择我们的产品。
祝好~
"""
```


常用于：

- 长文本
- 文档字符串（docstring）
- 多行内容


注意：

三引号中的内容都会被认为是字符串。

例如：

```python
"""
这是注释？
"""
```

实际上是字符串，而不是注释。


---

# 3. 字符串转义字符


当字符串内部需要使用特殊字符时，需要使用转义字符。


常见转义字符：

| 转义字符 | 作用 |
|-|-|
| \n | 换行 |
| \t | 制表符 |
| \\ | 表示反斜杠 |
| \' | 单引号 |
| \" | 双引号 |


示例：

```python
print("Hello\nPython")
```

输出：

```
Hello
Python
```


---

# 4. 字符串拼接


Python支持多种字符串拼接方式。


## 4.1 使用 + 拼接

示例：

```python
s = "Hello" + "Python"
```

结果：

```
HelloPython
```


特点：

优点：

- 简单直观

缺点：

- 适合少量字符串
- 多次拼接会产生新的字符串对象


---

## 4.2 join()方法


示例：

```python
s = " ".join(["Hello","Python"])
```

结果：

```
Hello Python
```


特点：

- 适合大量字符串拼接
- 效率更高


---

# 5. 不同类型数据拼接


字符串不能直接和其他类型拼接：

错误：

```python
a = 123
b = "hello"

print(a+b)
```


原因：

int类型和str类型不同。


需要类型转换：

```python
print(str(a)+" "+b)
```


使用：

```python
str()
```

可以将其他类型转换为字符串。


---

# 6. 字符串格式化输出


格式化输出：

可以将变量插入字符串中。


Python常见三种方式：

---

## 6.1 %占位符


示例：

```python
a = 123
b = "hello"

s = "a = %d, b = %s" % (a,b)
```


常用占位符：

|占位符|类型|
|-|-|
|%d|整数|
|%f|浮点数|
|%s|字符串|


输出：

```
a = 123, b = hello
```


---

## 6.2 format方法


示例：

```python
s = "a = {}, b = {}".format(a,b)
```


使用：

```python
{}
```

作为占位位置。


---

## 6.3 f-string（推荐）


Python 3.6以后支持。


示例：

```python
print(f"a = {a}, b = {b}")
```


特点：

- 写法简单
- 可读性强
- 当前开发中最常用
